# Return checklist — TODO: theme

All statuses start NOT RUN / NOT APPROVED. Record dates, revision, commands and
actual evidence paths; never equate one status with another.

| Stage | Status | Evidence |
| --- | --- | --- |
| Concept and maximum footprint approval | NOT APPROVED | TODO |
| Art production / coverage inventory | NOT RUN | TODO |
| Export-manifest SHA-256 | NOT RUN | TODO |
| Numeric/geometry checks | NOT RUN | TODO |
| Separate offline visual inspection | NOT RUN | TODO |
| Maintainer visual approval | NOT APPROVED | TODO |
| Runtime integration | NOT RUN | TODO |
| Retail live /reload loop | NOT RUN | TODO |
| Forever live /reload loop | NOT RUN | TODO |

Deliver:

- Brief, approved concept, exact original sources and their hashes.
- Prompts, actual input images, outputs and editing history per job.
- Native inventory: replace/shared/not applicable, with reasons.
- Export manifest listing path, canvas, source/hash, output/hash and tier pivot.
- Frozen bare casings, complete terminal/bridge masks and approved footprints.
- Theme-specific build/check/render commands and dependency versions.
- Numerical results bound to the current export-manifest hash.
- Complete 1x/2x bars: None/all choices, tiers, mirrors, 0/50/100% fills,
  prediction/absorb, default and custom scales. Fixed origin/union viewport.
- Cast None/on on normal/protected casings at defaults, 1x/2x.
- Whole resource assemblies, glass/specular, portraits, pet, compact frames,
  nameplate health/cast separation, minimap, buttons and small atlases.
- Separate inspected visual-review record with manifest and image hashes,
  reviewer/date, findings and comparison against the approved concept.
- Failing fixtures for terminal exposure, mounting-body cutout, oversize,
  erased bridges and bottom-aligned cast head.
- Checks that other themes, layouts, saved anchors and intentional nudges survive.
- Live Retail and Forever results separately: reload, switches/None, reset
  defaults, scales, combat, Edit Mode, prediction/threat and BugSack.
- Remaining issues, next action, Files touched. Release status is separate.

Do not package a new theme as accepted when numeric or visual evidence is
missing/stale. A workflow kit itself is not an accepted theme pack.
